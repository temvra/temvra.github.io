# temvra.github.io

Redirecciones de las direcciones antiguas de Temvra. La app vive en [temvra/app](https://github.com/temvra/app).

- `temvP/a/` reenvía los enlaces de compartir antiguos a `temvra.github.io/app/a/`, conservando lo compartido (lo que va detrás de `#`).
- `404.html` reenvía cualquier otra dirección de `/temvP/…` a `/app/…`.
